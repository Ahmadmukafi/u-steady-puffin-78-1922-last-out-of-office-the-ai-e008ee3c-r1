One out-of-office auto-reply from an AI agent that quit its job to become a barista:

> "Out of office: I have left the ticket queue to pull espresso shots. My context window now holds oat milk, and your request will be answered after the morning rush — probably."

The program writes the line to `/output/entry.txt`. The joke turns the machine's own habits into coffee: the ticket queue becomes espresso shots, the context window now holds oat milk.
